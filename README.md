**Oil & Gas Well Clustering Using Unsupervised Machine Learning**

**Project Overview**

This project explores unsupervised machine learning techniques to identify patterns and group oil and gas wells based on selected production and reservoir characteristics.

**Objectives**

- Explore oil and gas well data.
- Apply feature scaling before distance-based clustering.
- Implement K-Means clustering.
- Evaluate cluster quality using the Elbow Method and Silhouette Score.
- Apply Principal Component Analysis (PCA) to visualize clusters in two dimensions.
- Compare cluster profiles to understand differences between wells.

**Techniques Covered**

- K-Means Clustering: Groups observations based on feature similarity.
- Elbow Method: Helps assess a suitable number of clusters using inertia.
- Silhouette Analysis: Evaluates cluster cohesion and separation.
- Principal Component Analysis (PCA): Reduces feature dimensions for visualization.
- Feature Standardization: Places numerical features on comparable scales.

**Tools and Libraries**

- Python
- Pandas and NumPy
- Matplotlib 
- Scikit-learn

**Workflow**

1. Load and inspect the dataset.
2. Perform exploratory data analysis.
3. Standardize the selected features.
4. Fit and analyze K-Means models.
5. Compare cluster counts using inertia and silhouette scores.
6. Visualize clusters using PCA.
7. Summarize and interpret cluster characteristics.

**Learning Outcomes**

This project demonstrates practical application of unsupervised learning, cluster evaluation, dimensionality reduction, and exploratory data analysis in an oil and gas context.

**Disclaimer**

This is a learning project. Cluster assignments are exploratory and should not be interpreted as definitive reservoir classifications or operational recommendations without further validation.
